Follow-up to `2026-04-08-codebase-audit.md`. Scope: user-experience only. Dispatched 5 parallel agents across desktop chat, desktop shell/panes, desktop settings/onboarding, mobile app, and cross-cutting patterns. Findings are deduped and graded HIGH / MEDIUM / LOW by user impact (not engineering effort).

## Executive summary — the five UX bets

If you only touch five things from this audit, these are the ones that change how the product feels for a real freelancer:

1. **The agent gets stuck and the user doesn't know.** Tool approvals live in `QueuePane` but there is no chat-header badge, no toast, nothing inside the chat viewport telling the user "I'm waiting on you." If the user is mid-conversation they just see the agent stop streaming and go quiet. (`ChatPane.tsx:787-808`, `Sidebar.tsx:146`) — this is the single biggest "why isn't it working?" moment in the product.

2. **Destructive actions fire on one click.** Disconnect Google Calendar, delete a custom integration, remove a calendar entry, reject an approval — all instant, all unreversible, no confirm. (`IntegrationsModal.tsx:349-371`, `CalendarPane.tsx:~360`) Add a single shared `<ConfirmDialog>` primitive and wire it everywhere that mutates durable state.

3. **Mobile pairing has no success state.** User scans a QR → sees "Pairing…" → connection silently fails (desktop asleep, token bad, network) → black hole. No spinner, no retry, no "keep your desktop running" hint. (`scan.tsx:7-64`) First-run is the highest-leverage surface in the app; it can't have a silent failure path.

4. **Error messages are developer console output.** `ErrorBoundary` shows `error.message` raw. WS drops are announced with "Connection lost — reconnecting…" that auto-dismisses in 3s. API errors surface as toasts of the raw string from the server. (`ErrorBoundary.tsx:29`, `useAgent.ts:449-451`, `App.tsx:91-94`) There is no error-to-copy mapping layer anywhere. Freelancers will read "fetch failed" and assume the product is broken.

5. **The design system is a system by accident.** Dark mode is good, but there are ~8 raw font sizes, inconsistent spacing (`p-3` / `p-4` / `p-6` / `px-8 py-6` with no rhyme), mobile and desktop microcopy that don't match, three loading-state styles, and zero shared toast primitive. Every new feature compounds the drift. Codify a token scale (typography, spacing, loading, toast, confirm, empty-state) before the next feature batch.

Everything else in this report is elaboration, specific file:line pointers, and polish.

## 1. Desktop chat (`ChatPane` / `useAgent` / `VoicePill`)

### HIGH
- **Pending approval is invisible inside chat** (`ChatPane.tsx:787-808`): Tool approvals are segregated to `QueuePane`. A user deep in a conversation sees the agent fall silent with no clue it's blocked waiting for them. Add a sticky badge in the chat header + an inline "Agent is waiting on your approval → open queue" banner when `pendingApprovals > 0`.
- **Steer vs new-message mode is ambiguous** (`ChatPane.tsx:749-751`): When the agent is working and the user types, placeholder switches to "Type to steer the agent…" but Send has the same visual weight. User can't tell whether they're interrupting, correcting, or queuing. Needs a distinct visual mode (color tint, chip above composer, or a dedicated "Steer" button).
- **Streaming can't be stopped meaningfully** (`ChatPane.tsx:830-867`): Stop button aborts but there's no indication of whether partial work was saved, and no difference between "stop this message" vs "abort the whole agent run." Add explicit "Stop reply" vs "Abort task" affordances, and persist partial state if stopped mid-tool.
- **Placeholder vanishes on focus with nothing in its place** (`ChatPane.tsx:947-950`): Animated typing placeholder hides the moment the input is focused — new users see a completely blank input. Keep a static secondary prompt on focus (e.g. "Type a message or press Space to dictate").
- **Voice pill always on, in idle state** (`VoicePill.tsx:241-248`, memory `feedback_voice_pill_hidden.md`): Known issue — the idle audio bars are permanently in the viewport. Decide: either fade to near-invisible after 5s of silence, or hide entirely until a hotkey or mouseover reveals it.
- **Skill autocomplete has no keyboard hint** (`ChatPane.tsx:762-766`): `@research` triggers a dropdown, but there's zero indication the user should press ↑/↓/Enter. Add a tiny "↑↓ to navigate • Enter to select • Esc to dismiss" footer on the popover.

### MEDIUM
- **Attachment list overflows off-screen** (`ChatPane.tsx:906-917`): No scroll container; many files pushes the toolbar off the bottom.
- **Messages have no timestamps** (`ChatPane.tsx:818-828`): Long conversations have no time anchors — bad for a productivity tool.
- **Auto-scroll fights scrollback** (`ChatPane.tsx:669-682`): Double `requestAnimationFrame` snap-to-bottom on every chunk, even while the user has scrolled up to read history. Also no "jump to latest" pill.
- **Connection errors auto-dismiss in 3s** (`useAgent.ts:449-451`): User mid-edit misses them entirely. Persistent banner until the user dismisses or reconnects.
- **Voice dictation always appends to end** (`ChatPane.tsx:608-611`): Can't dictate into the middle of a composing message; cursor position is lost.
- **Connection status is a 2px dot in the header** (`ChatPane.tsx:787-808`): Too subtle. Needs an explicit colored status chip during degraded states.

### LOW
- Thinking shimmer-text has poor contrast in light mode (`ChatPane.tsx:837-839`).
- File deck has no left/right arrow-key navigation (`ChatPane.tsx:446-476`).
- User messages can't be copied (`ChatPane.tsx:820-823`).
- Mic hold-to-dictate has no 3s threshold indicator (`ChatPane.tsx:953-967`).
- Welcome copy is warm, queue empty state is robotic — tonally mismatched (`ChatPane.tsx:43-50` vs `QueuePane.tsx:97-99`).
- Typing placeholder animation restarts every time the suffix list changes (`ChatPane.tsx:191-242`).

### Strengths to preserve
- File attachment UX (stacked card deck, lightbox, PDF preview) is genuinely polished (`ChatPane.tsx:351-481`).
- Research-agent progress rendering during long tasks gives good feedback (`ChatPane.tsx:841-858`).
- Voice pill state machine transitions are smooth and distinct.

## 2. Desktop shell & panes (sidebar, detail/queue/skills/team/files/calendar/canvas/activity/overlay)

### HIGH
- **New queue items are silent everywhere except the sidebar** (`Sidebar.tsx:146`): Badge lives only on the nav item. A user in FilesPane or CanvasPane will never know a new approval arrived. Pipe queue changes to a global toast or header indicator.
- **DetailPane has no way back** (`DetailPane.tsx:87-88`): No breadcrumb, no back chevron — if the user arrives via a link or sidebar click they have to know to click Queue again.
- **FilesPane empty state has no upload CTA** (`FilesPane.tsx:207-215`): First-run users see a blank pane. Needs a visible "Drop files here" zone or Upload button.
- **QueuePane "All clear" is a dead-end** (`QueuePane.tsx:44-45`): Gives the user no sense of what the agent is doing while queue is empty — use it to show "Agent is idle — ask it something in chat."
- **Canvas parse errors are hidden in the iframe** (`CanvasPane.tsx:141-147`): Only shows "parse error" with truncated text. Full error should be expandable so the user can actually debug.
- **TeamPane notes spinner has no timeout** (`TeamPane.tsx:336-341`): Bounces forever if the relay is unreachable. Add a 5s timeout + fallback error state.

### MEDIUM
- **Inter-pane changes don't propagate** (`App.tsx:126-228`): Chat creates a file → FilesPane doesn't know; agent schedules an event → CalendarPane doesn't refresh. User has to manually click tabs to verify anything happened.
- **SkillsPane list grows unbounded** (`SkillsPane.tsx:207-227`): No virtualization. 50+ skills will drag.
- **CalendarPane has no active timezone label** (`CalendarPane.tsx:160-169`): "Today" works in user's timezone but nothing tells them which one.
- **Sidebar integrations cap at 8 with no count badge** (`Sidebar.tsx:155-185`): 9th+ integration silently hidden behind "Manage."
- **DetailPane edit has no unsaved-changes warning** (`DetailPane.tsx:74-105`): Navigate away → draft lost.
- **ActivityTray has no cancel affordance** (`ActivityTray.tsx:14-62`): Can't stop a single step from the tray.
- **QueuePane done items are non-interactive** (`QueuePane.tsx:78-94`): No hover, no archive, no delete — they pile up forever.
- **TeamPane General channel empty state doesn't teach** (`TeamPane.tsx:393-398`): "Team messages will appear here" — never explains how to mention an agent.
- **FilesPane folder depth has no visual nesting cue** (`FilesPane.tsx:424-426`): Breadcrumbs exist but no tree indentation.

### LOW
- Sidebar theme toggle doesn't persist across sessions (`Sidebar.tsx:193-202`).
- SkillsPane `BUILTIN_DETAILS` is hard-coded metadata (`SkillsPane.tsx:19-47`).
- CalendarPane doesn't remember last-selected view (`CalendarPane.tsx:118`).
- TeamPane mention highlight is too subtle (`TeamPane.tsx:183-191`).
- DetailPane metadata doesn't reflow well on narrow screens (`DetailPane.tsx:128`).
- FilesPane search placeholder/icon missing (`FilesPane.tsx:390-391`).
- OnboardingTour overlay is blocking rather than dismissible in-flow (`App.tsx:247-257`).
- Empty-state iconography repeats across panes — looks like a palette-swap (`QueuePane.tsx:96-100`, `SkillsPane.tsx:209-215`, `TeamPane.tsx:220-225`).
- `overlay.tsx` has no ErrorBoundary → VoicePill crash kills the whole overlay window (`overlay.tsx:1-11`).

### Strengths to preserve
- Pane layouts (header/scroll/footer) are consistent — the skeleton is right.
- Keyboard shortcuts for the common cases (Esc cancel, file selection) are thoughtful.
- Dark mode coverage is complete across all panes.

## 3. Settings / onboarding / integrations / updater

### HIGH
- **Activation code required at first launch, no demo mode** (`OnboardingTour.tsx:175-214`): No way to poke around before committing. First-time users without a code are locked out of the app entirely.
- **Integrations only show "connected" or "not connected"** (`IntegrationsModal.tsx:375-378`): No "token expired," "rate-limited," "needs re-auth." Users will silently lose OAuth tokens and not realize until the agent fails.
- **Integration delete is zero-friction** (`IntegrationsModal.tsx:364-371`): One click, gone, no confirm. Custom integrations with hours of setup can evaporate.
- **Credential fields have no live validation** (`IntegrationsModal.tsx:281-324`): User pastes a bad API key, submits, gets a cryptic error after the fact.
- **Voice hotkey shows "Ctrl" on Mac** (`SettingsPane.tsx:323`): Hardcoded `.replace('Control', 'Ctrl')` — Mac users will look for a Ctrl key.
- **Settings auto-save is silent** (`SettingsPane.tsx:13-37`): Debounced writes with no "Saved" indicator. If the save fails (network, 500, backend bug) the user will never know.

### MEDIUM
- OnboardingTour highlight overlay is too faint — `bg-black/15` doesn't separate the target from the rest (`OnboardingTour.tsx:147-151`).
- Tour step counter is off by one (`OnboardingTour.tsx:260-261`).
- Integration search "No results" copy doesn't echo the query (`IntegrationsModal.tsx:447-448`).
- WhatsApp QR only visible while disconnected — can't re-pair another device without disconnecting first (`IntegrationsModal.tsx:270`).
- Model selection shows per-token price but no "est. monthly cost at your current usage" (`SettingsPane.tsx:408-443`).
- Token usage is last-30-days flat number, no trend / delta vs prior period (`SettingsPane.tsx:480-482`).
- CapabilityCard has no cancel/undo after confirm (`CapabilityCard.tsx:142`).
- ErrorBoundary is generic "Something went wrong" (`ErrorBoundary.tsx:23-45`).
- Updater waits 5s to check → surprise prompt 5s into the app (`useUpdater.ts:27-42`).
- Update dismiss is permanent — no "remind me tomorrow" (`useUpdater.ts:68-70`).
- Theme toggle instant but no preview and no system-follow preference (`useTheme.ts:3-12`).

### LOW
- Activation code success state has no confirmation feedback (`OnboardingTour.tsx:175-214`).
- Auto-detected timezone value not surfaced to the user (`SettingsPane.tsx:172-179`).
- Custom instructions label reads like help text (`SettingsPane.tsx:217-226`).
- Logo upload silently rejects unsupported files (`SettingsPane.tsx:813`).
- Voice hotkey is read-only, can't remap (`SettingsPane.tsx:323`).
- Credential fields don't mark required vs optional (`IntegrationsModal.tsx:280-324`).
- Mobile QR relay-not-configured state flashes "Loading…" first (`IntegrationsModal.tsx:262`).
- Category counts disappear when searching integrations (`IntegrationsModal.tsx:452-453`).
- Admin tokens list has no copy-to-clipboard button (`SettingsPane.tsx:621-663`).
- Onboarding tour doesn't skip steps that are already complete (`OnboardingTour.tsx:62-119`).

### Strengths to preserve
- Integrations grid → detail navigation is well designed (breadcrumb + escape).
- Debounced auto-save pattern is right — just needs a tiny acknowledgment.
- Autonomy-level radio copy is clear and non-jargony (`SettingsPane.tsx:116-121`).
- Brand color picker has live preview (`SettingsPane.tsx:740-897`).

## 4. Mobile app

### HIGH
- **Scan success has no signal** (`scan.tsx:59`): "Pairing…" then nothing. No spinner, no success modal, no error if the WS handshake fails after credentials save.
- **"Desktop is off" is not a handled state** (`scan.tsx`): The pairing flow will happily save credentials against a desktop that isn't running and then hang on the chat tab. Needs explicit pre-check and "Make sure your desktop app is running and awake" hint.
- **Voice session is silently dropped on tab switch** (`voice.tsx:34-48`): `useFocusEffect` cancels recording/TTS without telling the backend, so any in-flight audio is orphaned. Should either commit the audio or explicitly cancel with feedback.
- **Voice send failure has no error state** (`voice.tsx:65-79`): If `stopRecordingAndGetBase64()` returns null, the code silently retries `startListening()`. User hears nothing, sees nothing. Needs explicit "Mic error, tap to retry" state in the orb.
- **Chat doesn't auto-scroll on reconnect** (`(tabs)/index.tsx:120-135`): After offline→online, user has to manually scroll to see new messages.
- **No reconnect affordance on WS drop** (`(tabs)/index.tsx:105-109`, `voice.tsx:205-207`): Banner is purely informational. No retry button, no "reconnecting in Xs…" countdown.
- **Desktop credentials can go stale with no recovery UX** (`useAgent.ts:54-213`): If the token is revoked server-side, the user has no settings-level path to re-pair except by knowing to delete + re-scan.

### MEDIUM
- Scan screen has no tap-lockout during the 500ms–2s post-scan window (`scan.tsx:7-64`).
- Voice orb idle state is too faint to read at-a-glance (`VoiceOrb.tsx:32-53`, 149).
- Voice state labels flash during rapid transitions (`voice.tsx:144-156`).
- Chat input disabled when offline but no explanation in placeholder (`(tabs)/index.tsx:165`, 179-182).
- Image file preview modal has no obvious dismiss (`MessageBubble.tsx:88`).
- Code blocks don't horizontally scroll on small screens (`MessageBubble.tsx:198-199`).
- Tab switches lose scroll position in chat (`(tabs)/index.tsx`).
- Settings "managed from desktop" message is 11px and easy to miss (`settings.tsx:113-115`).
- Notification mode radio buttons have 10×10 selection dots — hard to see active state (`settings.tsx:71-92`).

### LOW
- Scan frame has no "align QR here" instruction text (`scan.tsx:56-62`).
- Error banner auto-dismisses in 5s without countdown (`useAgent.ts:156`).
- Voice orb container is fixed 80px, idle state looks cramped (`VoiceOrb.tsx:134-156`).
- No haptic feedback on chat send (`(tabs)/index.tsx:73-81`).
- Keyboard doesn't dismiss after send (`(tabs)/index.tsx:73-81`).
- Timestamp formatting is locale-default only (`MessageBubble.tsx:109-112`).
- VoiceOrb animation cleanup has a race during rapid unmount (`VoiceOrb.tsx:25-30`).
- Relay URL in settings ellipsizes in a confusing place (`settings.tsx:63-65`).
- Tab icons missing `accessibilityLabel` (`(tabs)/_layout.tsx:35-66`).
- Chat empty-state spinner is low-contrast gray (`(tabs)/index.tsx:131`).
- Image preview modal uses fixed 400px height (`MessageBubble.tsx:174-177`).
- Settings "Re-scan QR Code" button has no explanation of what happens next (`settings.tsx:97-102`).

### Strengths to preserve
- Connection dot in tab headers is consistent and always visible.
- Voice orb states (idle / listening / thinking / speaking) are visually distinguishable without labels.
- WS auto-reconnect with health checks and app-state listeners is robust under the hood — the missing piece is exposing its state in the UI.
- Voice flow is non-blocking (keeps session open, auto-listens after agent finishes).

## 5. Cross-cutting patterns (the compounding stuff)

### HIGH
- **No typography scale** — raw px values scattered across desktop (`ChatPane.tsx:169,512,620,789,838`) and mobile StyleSheets (`(tabs)/index.tsx:194-361` uses 19, 14.5, 13, 12, 10). Define an xs/sm/base/lg/xl scale in Tailwind config + mobile constants and migrate. Every future feature drifts without this.
- **Destructive actions have no confirm primitive** — `IntegrationsModal.tsx:349-352` disconnect, `IntegrationsModal.tsx:364-371` delete integration, `CalendarPane.tsx:~360` delete entry, `CalendarPane.tsx:~375` disconnect Google Calendar, all fire on click. Build one shared `<ConfirmDialog>` and use it everywhere.
- **No error→user-copy translation layer** — `ErrorBoundary.tsx:29` shows `error.message`, `App.tsx:91-94` shows raw server error strings, mobile `(tabs)/index.tsx:105-109` shows raw WS errors. Need a mapping function like `humanizeError(err): { title, description, action }`.
- **No unified loading pattern** — mix of skeleton (`ChatPane.tsx:306-308`, `FilesPane.tsx:~380`), spinner (`(tabs)/index.tsx:131`), and silent loads (`SettingsPane.tsx` form submits). Extract `<Skeleton>`, `<Spinner label="..."/>`, and an `isSaving` pattern on forms.
- **No global toast system** — errors fire from `App.tsx:91-94` as a fixed top-center div, mobile uses an inline `<View>` with no queueing (`(tabs)/index.tsx:105-109`). Extract a `<Toast>` primitive with 4s default, dismiss button, queueing.
- **Mobile and desktop microcopy diverge** — desktop welcome: "Hey — I'm your personal AI assistant, running right here on your machine…" (`ChatPane.tsx:45`); mobile welcome: "Hello. I'm Co-Agent. I'm watching your queue and ready to help. What do you need?" (`(tabs)/index.tsx:125`). Create a shared `strings.ts` / `copy.ts` and consume from both platforms.

### MEDIUM
- Icon-only buttons lack `aria-label` across the app (`ChatPane.tsx:927-934`, `ChatPane.tsx:953-967`, `Sidebar.tsx:43-62`).
- Form validation doesn't hint, doesn't clear on typing, doesn't show required markers (`CapabilityCard.tsx:136-137`, `IntegrationsModal.tsx:287-315`).
- Modals don't trap focus or restore focus on close (`IntegrationsModal.tsx:152-160`, `CapabilityCard.tsx`).
- Checkboxes reimplemented twice — `CapabilityCard.tsx:75-81` (custom emerald SVG) vs `IntegrationsModal.tsx:392-396` (raw HTML input). Extract a `<Checkbox>` from ui/.
- Color contrast likely fails WCAG AA in some dark-mode states (`ChatPane.tsx:851` `text-neutral-400`, `Sidebar.tsx:50` hover). Audit with WebAIM.
- Empty states are mostly just text strings — need an `<EmptyState icon title description cta />` pattern (`QueuePane.tsx:96-99`, `(tabs)/index.tsx:120-135`).
- Date/time formatting is done three different ways (`ChatPane.tsx:90-91,140,159`, `MessageBubble.tsx:109-112`, `QueuePane.tsx:23-28`). Share a `formatTime()` / `formatRelative()` util.
- No responsive breakpoints — sidebars are fixed widths, no narrow-viewport handling (`QueuePane.tsx:39`, `styles.css` has no breakpoints defined).
- Keyboard shortcuts are undocumented — space-hold dictation (`ChatPane.tsx:614-662`), Esc to cancel (`App.tsx:38-46`). Add a `?` help overlay or a kbd palette.

### LOW
- `Button` variants under-used — `destructive` exists but never called. `IntegrationsModal.tsx:350` uses raw classes for Disconnect.
- Card padding varies (p-3 / p-4 / p-6 / px-8 py-6) with no system — pick a scale.
- Spinner label sometimes missing when `toolLabel` is null (`ChatPane.tsx:830-860`).
- Queue badge colors (violet/emerald/amber/sky) have no legend (`QueuePane.tsx:7-21`).
- `IntegrationsModal.tsx:184-226` and 464-505 duplicate the same inline SVGs.
- Placeholder voice mixes tones (action-oriented vs status) (`ChatPane.tsx:939,948`, `TeamPane.tsx:~565`).
- Button copy mixes nouns and verbs — "Run Now" (`ChatPane.tsx:120`) vs "Connect" / "Confirm" (`IntegrationsModal.tsx:336,357,360`). Use imperative verbs everywhere.
- File deck chevron buttons have no `aria-label` / `title` (`ChatPane.tsx:448-476`).
- Focus ring uses `--ring: 240 5.9% 10%` — invisible on light backgrounds (`styles.css:25`, `ui/button.tsx:8`).
- Modal backdrop click inconsistency: IntegrationsModal closes on backdrop, CapabilityCard has no backdrop at all.

### Strengths to preserve
- Dark mode is comprehensive and correct — no hardcoded colors leak.
- Markdown rendering (remark-gfm desktop + react-native-markdown-display mobile) looks nearly identical across platforms.
- File UX (thumbnail, lightbox, PDF preview, stacked deck) is polished end-to-end.
- Voice state machine transitions are smooth and readable.
- Heartbeat/connectivity dot is always-visible at a glance on both platforms.

## Recommended execution order

Grouped so each batch ships something the user can feel, not just internal cleanup.

### Batch A — "Stop losing user work" (1–2 days)
1. Shared `<ConfirmDialog>` primitive + wire it to every destructive action (integrations delete/disconnect, calendar delete, approval reject).
2. DetailPane unsaved-changes warning on navigate-away.
3. Scan screen success/error states + "keep your desktop running" hint + tap-lockout during the handshake window.
4. Voice session tab-switch: explicit cancel with feedback, not silent drop.
5. Update-dismiss "remind me tomorrow" option.

### Batch B — "Tell the user what's happening" (2–3 days)
1. Pending-approval badge in chat header + inline "agent is waiting" banner.
2. `humanizeError(err)` mapping layer + shared `<Toast>` primitive with queueing.
3. Settings "Saved" micro-indicator on auto-save success (+ failure state).
4. Integration status chip beyond just connected/disconnected: "Connected" / "Expired" / "Rate limited" / "Error."
5. Loading pattern unification: `<Skeleton>`, `<Spinner label>`, `isSaving` on forms.
6. Reconnect affordance on mobile + desktop WS drop banners.

### Batch C — "Design system" (2–4 days, infra work)
1. Typography scale token + migration (codemod the raw `text-[12.5px]` / StyleSheet sizes).
2. Spacing scale audit + enforcement in Tailwind config.
3. Shared `strings.ts` for microcopy — reconcile desktop/mobile welcome, connection, error voice.
4. Focus ring color fix + focus-trap on modals.
5. Extract `<Checkbox>`, `<EmptyState>`, `<Toast>`, `<ConfirmDialog>` into `components/ui/`.
6. Accessibility pass: `aria-label` on every icon-only button, `aria-current` on active nav, tab icons on mobile.

### Batch D — "Polish" (ongoing)
Everything under LOW in each section. Pick up opportunistically while in nearby code.

## Out of scope

Not covered by this audit (flag them separately if needed):
- **Performance**: virtualization, bundle size, render-count audits.
- **Marketing/landing surface**: this is the in-app UX only.
- **Localization/i18n**: all copy is English; no audit of translation workflow.
- **Telemetry/analytics UX**: what events fire, what the user sees about data collection.
- **Pricing/billing UX**: Stripe / checkout / paywall flows (covered separately in launch checklist).
